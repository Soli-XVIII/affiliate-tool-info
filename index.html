Pin-Scheduler-AT

A private, single-user tool for preparing and publishing my own Pins. Not a public service.

What it is

Pin-Scheduler-AT is a web tool that I run on my own server. I use it to prepare Pins for my own Pinterest business account: an image, a title, a description and a link to a product page or a partner comparison page. Every Pin is reviewed and approved by me before it is published, and Pins are published at a low, rate-limited pace.

How it uses the Pinterest API

  • It acts only on my own Pinterest account, using an OAuth 2.0 access token issued by Pinterest for that account.
  • Scopes: boards:read to list my boards, pins:write (with boards:write, which Pinterest requires to create a Pin on a board) to create Pins on them and pins:read to show the status of Pins it created. The tool never creates, edits or deletes boards.
  • It does not access any data of other Pinterest users, does not scrape Pinterest, does not use login credentials or session cookies, and does not automate follows, likes, comments or messages.
  • Pins that contain affiliate links are labeled as advertising (#ad / #Werbung).

Who can use it

Only I can. There is no public registration, no user accounts for third parties and no public interface. Because of this, the tool does not collect data from visitors. See the privacy policy for details.
